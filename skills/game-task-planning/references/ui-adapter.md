# 통합 UI 연결 · v2

같은 묶음의 UI 스킬과 schema를 사용한다. 별도 UI 설치는 필요 없다. 직접 호출에도 적용한다. 화면·상태·target, 원본 규칙 locator/hash, 역할 카드, 언어와 고정 검증 범위를 기존 인계 기록으로 전달한다. UI 표를 복제하지 않고 공통 envelope만 연결한다.

## 최소 개입 결정 규칙

아래 순서로 처리하며 단계 종료를 사용자 응답 대기로 바꾸지 않는다.

1. 현재 요구에 유효한 기존 결정과 승인을 재사용한다. 승인된 동작·시각 결과로 복구하거나 유지하는 작업은 원본 승인과 현재 후보의 대응 근거를 기록하고 진행한다. 예전 빌드의 검증 결과를 새 빌드의 통과로 복사하지 않는다.
2. 요청 범위 안의 구현 방법·정렬·도구 선택은 담당자가 결정한다. 취향·제품 선택도 명시된 위임 범위 안이면 감독 또는 지정된 결정자가 선택한다. 작성자의 취향만으로 승인하지 않는다.
3. 새로운 제품 선택이라도 명시적 위임이 있으면 그 범위에서 결정한다. 요구 충돌, 결정에 필수인 입력 부재, 위임 밖의 중대한 제품 선택, 명시적으로 사람에게 남긴 승인만 사용자에게 묻는다. 먼저 근거·추천안·영향·검토 가능한 후보를 준비하고, 감독이 남은 질문을 묶는다. 무응답은 승인이나 위임이 아니다. 영향 없는 작업은 계속한다.

UI 문서의 approved/selected 및 fidelity decision은 이 규칙으로 충족한다. 실제 사람 승인, 위임 결정, 기존 승인 재사용을 서로 다른 근거로 기록하며 자동 결정을 사람 승인으로 표시하지 않는다. 프로젝트/사용자가 명시한 human-only 조건은 유효한 권한 변경 없이 해제하지 않는다. 전문 역할의 산출물 종료는 감독에게 반환하는 경계이며, 충족된 다음 단계를 시작할 때 재승인을 요구하지 않는다.

## 초기 화면과 수정 반복

[빠른 수정 경로](ui-fast-iteration.md)는 시각 선택이 미정이어도 알려진 실제 내용/target/상태의 편집 가능한 화면 초안을 허용한다. 정식 승인 입력은 formal candidate 진입에 적용하며 초안을 차단하지 않는다. 부분 runtime 검증에서는 현재 재관측과 검증된 역사적 증거 재사용을 구분하고 전체 필수 coverage와 원래 raw identity를 유지한다.

## 기존 인계 기록에 남길 값

| 값 | 소비 규칙 |
| --- | --- |
| decision ID, scope, candidate/revision, authority source | 원문 요청·기존 승인·위임 출처와 정확한 후보를 연결 |
| confirmed/delegated/proposed/unresolved, 선택/이유, 결정자 | delegated에는 실제 위임과 선택 필요. proposed/unresolved는 승인 아님 |
| 기존 승인 재사용 근거, 변경·보존 조건, 남은 human-only 조건 | 새 디자인·변경된 제약에 무조건 승계를 금지 |
| 현재 build/composite fingerprint, evidence IDs, 독립 판정 | 새 빌드는 현재 증거로 검증. 위임이나 과거 승인은 검증 대체 불가 |

명세·방향·목업은 해당 내용의 결정 근거를 각각 연결한다. 다른 문서의 승인만으로 자동 승인하지 않는다. 컴포넌트 catalog는 기존 schema와 fingerprint를 유지하고, 위임 승인자는 유효한 출처로 프로젝트 approvalAuthorities에 선언되어야 한다. 미등록 권한을 validator 통과용으로 만들어 넣지 않는다.

## 독립 검증과 반환

산출물 작성자와 별도 서브에이전트가 고정 기준 안에서 검증한다. 위임 결정자도 자기 산출물의 독립 검증자가 될 수 없다. 필수 art/UI 판정, 현재 증거, 승인된 편차 범위는 유지한다. P3 편차도 같은 결정 규칙으로 해당 편차·후보를 수용해야 하며 P0/P1/P2를 위임으로 면제하지 않는다.

검증 오류는 작성자가 반환된 범위만 수정하고 별도 검증자가 영향 기준만 재검증한다. 기존 재시도 한도를 지키며 범위 밖 발견은 새 작업이나 gate로 만들지 않는다. 검증 불가나 한도 소진은 막힌 범위와 근거를 반환하며 통과로 바꾸지 않는다.
